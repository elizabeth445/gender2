# Проект «Маленьке диво в джунглях»

- React + TypeScript + Vite; украинский интерфейс и акварельная концепция из `design.md`. Данные события — `src/eventConfig.ts`.
- Полная локальная проверка: `npm run verify` (секреты, lint, форматирование, шрифты, Playwright, TypeScript и production build). Общие правила GitHub находятся в глобальном `~/.codex/AGENTS.md`; здесь они не дублируются.
- `public/art` и `public/fonts` — рабочие ресурсы; `art-source` — оригиналы иллюстраций, `licenses` — лицензии. Не считай исходные PNG дублями оптимизированных WebP.
- `output`, `playwright-report`, `test-results`, `dist` — генерируемые каталоги. После просмотра результатов очистки их можно удалить; эталонных screenshot-тестов в этом проекте нет.
- Vercel: сборка `npm run build`, выходной каталог `dist`. Backend и переменные окружения не требуются; конфигурацию публикации автоматически не подключать.

## Разрешённый GitHub workflow этого проекта

- Единственный целевой репозиторий: `https://github.com/elizabeth445/gender2.git`, remote `origin`, ветка `main`.
- Пользователь заранее разрешил обычные commit и push в этот репозиторий после каждой успешно завершённой задачи на изменение сайта. После локальных правок выполни аудит/очистку, `npm run verify` и нужную браузерную проверку; проверь status, diff, staged diff, remote и ветку. Затем создай коммит с понятным названием, отправь его в `main` и проверь SHA на GitHub. Повторное подтверждение не требуется; пустые коммиты не создавать.
- Это проектное разрешение заменяет глобальное требование отдельной команды на каждый обычный commit/push только для `elizabeth445/gender2`. Оно не разрешает deploy, force push, удаление истории, публикацию секретов или отправку в другой репозиторий/ветку.
- При конфликте, изменении remote или ошибке Git не перезаписывай чужие изменения; останови отправку и сообщи о проблеме. Сохраняй существующую историю и несвязанные изменения.
- После задачи кратко сообщай по-русски, что изменено, какие проверки прошли, успешен ли push, и указывай SHA коммита.
