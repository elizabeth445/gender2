# Маленьке диво в джунглях

Украиноязычное приглашение Олены и Артема на 22 мая 2027 года. Самостоятельный проект на React, TypeScript и Vite. Анимации — GSAP, @gsap/react и ScrollTrigger. Без backend и сторонних запросов при посещении.

## Локальный запуск

```sh
source ~/.codex/bin/frontend-env.sh  # только если Node.js отсутствует в PATH
npm ci
npm run dev -- --port 5319 --strictPort
```

Адрес: http://127.0.0.1:5319/. Можно запустить двойным щелчком `start.command`. Нужен Node.js 22.12+.

```sh
npm run build          # TypeScript и production-сборка в dist/
npm run preview -- --port 5319
npm test               # отдельный Chrome: desktop, touch и reduced motion
npm run check:fonts    # наличие всей украинской азбуки в локальных TTF
npm run verify         # секреты, lint, форматирование, шрифты, тесты, TypeScript и build
```

## Где редактировать событие

`src/eventConfig.ts` — родители, дата, время, часовой пояс, город, адрес, срок RSVP и программа. `startsAt` и `endsAt` должны содержать правильное UTC-смещение для новой даты; для демонстрационного 22.05.2027 в Киеве указано +03:00. Одновременно обновите текстовые `dateLabel`, `shortDate` и `time`. Поля пола ребёнка нет.

Чтобы включить маршрут, заполните **реальный проверенный** `address` и `directionsUrl` с HTTPS-ссылкой на карту. Пока адрес пуст, ссылки на маршрут нет. Формат ICS — UTC, с корректным переносом строк по 75 байтам и экранированием текста.

## Что работает

- Открытие приглашения листвой, пропуск и повтор; полный reduced-motion вариант.
- Рост лианы на полях, книжный переход между главами и короткая финальная анимация.
- Прогноз: локальное сохранение, повторный выбор; без выдуманных голосов и раскрытия пола.
- Таймер до 15:00 Europe/Kyiv, остановка на нуле; скачивание календаря.
- Секрет обезьянки по клику, касанию листа или кнопке; доступен с клавиатуры.
- RSVP: имя, явный выбор присутствия, пожелание, валидация, фокус на ошибке, сохранение и редактирование.

RSVP и прогноз хранятся **только в localStorage текущего браузера**. Они не передаются организаторам, не синхронизируются между устройствами и могут исчезнуть при очистке данных браузера. Если хранилище заблокировано, интерфейс сообщает об этом. Ключи включают ID события и версию схемы; для нового события измените `id`.

## Визуальные материалы

Источники, происхождение и лицензии: `ASSETS.md`, файлы SIL OFL — в `licenses/`. Все используемые изображения — в `public/art/`, шрифты — в `public/fonts/`. Никаких личных профилей браузера, платных API или публикации не используется.

Два описанных в задании референса не были доступны среди вложений; точное сравнение с ними не выполнено. Для иллюстраций создан самостоятельный акварельный набор через встроенный ImageGen. Концепция и палитра зафиксированы в `design.md`.

## Проверки

Playwright: 320, 390, 768, 1024, 1440 px, отсутствие горизонтального переполнения, интерактивность, сохранение и редактирование, заблокированное хранилище, скачанный ICS, окончание таймера, axe WCAG A/AA. Скриншоты: `output/qa/`, отчёт: `playwright-report/`. Это эмуляция Chrome, а не проверка на физических устройствах; Safari и Firefox отдельно не проверялись.

Скриншоты, отчёты, кэши и `dist/` генерируются заново и исключены из Git. Проверка `npm run check:secrets` ищет типичные ключи, токены, пароли и приватные ключи без вывода значений; она эвристическая и не заменяет ручной просмотр diff перед отправкой.

## Подготовка к GitHub и Vercel

Репозиторий проекта: `https://github.com/elizabeth445/gender2`, ветка `main`. Пользователь заранее разрешил обычные commit и push после каждой успешно завершённой задачи на изменение сайта. Перед отправкой: аудит ненужных файлов и зависимостей, `npm run verify`, нужная проверка desktop/mobile, затем просмотр `git status`, diff, staged diff, remote и ветки. После push необходимо сверить SHA на GitHub. При конфликте отправка останавливается; force push и перезапись истории запрещены. Сама команда `verify` ничего не публикует.

Для Vercel: команда сборки `npm run build`, выходной каталог `dist`. Backend, секреты и дополнительный конфиг Vercel этому сайту не нужны. Подключение репозитория и публикация выполняются только по отдельной команде.
