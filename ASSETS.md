# Источники визуальных материалов

## Иллюстрации

Четыре исходных PNG-иллюстрации созданы встроенным инструментом OpenAI ImageGen. Для карточек прогноза тем же инструментом сделаны две версии слонёнка с голубым и розовым бантом на основе существующего рисунка; поза и масштаб сохранены. Это сгенерированные иллюстрации с акварельной фактурой, а не изображения стороннего художника, покупные клипарты или вырезки из референсов. Им не приписывается сторонняя стоковая лицензия или статус public domain. Использование регулируется условиями сервиса генерации.

В проекте находятся оптимизированные WebP с сохранённым альфа-каналом:

- `public/art/giraffe.webp` — жираф.
- `public/art/elephant.webp` — слонёнок.
- `public/art/elephant-blue.webp`, `public/art/elephant-pink.webp` — одинаково кадрированные слонята с голубым и розовым бантом для прогноза, 600 × 624 px.
- `public/art/monkey.webp` — обезьянка на лиане.
- `public/art/monkey-character.webp`, `public/art/monkey-branch.webp` — отдельно подготовленные через встроенный ImageGen прозрачные слои персонажа и неподвижной ветки, 600 × 900 px; исходный объединённый рисунок сохранён для остальных сцен.
- `public/art/foliage.webp` — тропическая ботаническая композиция.
- `public/art/nursery-balloon.webp` — шалфейно-молочный воздушный шар с облаками, 400 × 600 px.
- `public/art/baby-clothesline.webp` — детская одежда на верёвочке с эвкалиптом, 720 × 480 px. Обе новые иллюстрации созданы встроенным ImageGen по стилю пользовательского референса `_.jpeg`, без копирования его текста или композиции.

PNG-оригиналы сохранены в папке `art-source/`. Промпты: `art-source/prompts.md`. Листва используется как отдельный самостоятельный слой. У слонят мягко деформируются только области ушей через SVG-фильтр; отдельные суставы не имитируются. Обезьянка перемещается целым подготовленным слоем относительно неподвижной ветки. Анимации учитывают reduced motion.

Первоначальные описанные референсы не были доступны. Позднее пользователь передал `_.jpeg`: его акварельная фактура и шалфейно-молочная палитра использованы для двух новых самостоятельных иллюстраций. Исходное изображение в репозиторий не копировалось.

## Шрифты

Скачаны из официального репозитория Google Fonts, размещены локально. Лицензия каждого — SIL Open Font License 1.1; тексты в `licenses/`.

- Bona Nova Regular / Italic: https://github.com/google/fonts/tree/main/ofl/bonanova
- Marmelad Regular: https://github.com/google/fonts/tree/main/ofl/marmelad
- Neucha: https://github.com/google/fonts/tree/main/ofl/neucha

Bona Nova выбран после просмотра реальных украинских заголовков; Marmelad — для спокойного короткого набора; Neucha — только для подписей. Наличие всей украинской азбуки проверяется `scripts/check-fonts.py` по таблицам cmap файлов TTF.

## Декоративные элементы

Небольшие линейные SVG-маркеры программы, веточка, бабочка, лиана, фактура бумаги и favicon созданы в коде проекта. Сторонние изображения, логотипы, фотографии и эмодзи не используются.
